# DevTools Panel

Open DevTools (F12) and choose the **HitAPI** tab. The panel is the same app as the toolbar popup, shown for the tab DevTools is inspecting:

- start and stop capture
- watch requests arrive live
- **⇄ Workbench** tab: the full Request Workbench inside DevTools. **⇄ Open in Workbench** on a captured
  request opens it right there, next to the capture list. The panel's Workbench keeps its own draft, separate
  from the Workbench tab; **Open in a tab ↗** opens the tab version.
- add requests to suites and report bugs (signed in)
- import specs and run suites (signed in)

Unlike the popup, the panel stays open while you click around the page, which makes it the easier way to capture longer flows.
